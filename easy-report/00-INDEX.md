## 처리 특이사항 (P3 집필자가 반드시 볼 것)

1. **`conclusion`(5부)은 거대 섹션(33,111자)** — 단일 장에 넣지 않고 내용별로 쪼갠다:
   - "한 문장으로" → 0장 프롤로그 훅으로.
   - "구성 명제별 신념도"·"채택/폐기/은유로 확정" → 9장의 데이터 부록(표 형태 유지 가능 — 완역이되 표는 표로).
   - "검증 루프 회차 로그"(회차 1–84 전체) → 9장 서사에 **압축 요약**으로 녹인다(문장 하나하나 완역이 아니라 "무엇이 있었는지"의 무손실 요약 — 상세는 표/부록 참조로 대체 가능. 이건 원칙 2의 예외로 미리 승인: 84회차 로그를 전부 산문화하면 무손실이 오히려 가독성을 해친다. 대신 **핵심 전환점**(회차 43 반전·73 공유 맹점 확증·78 물리 기각·79 예측 등재·80–84 세계 편)은 각각 문단으로 완역).
2. **`prediction`(8부, 예측력 문제)**은 이 세계관 최강의 자기 비판(#19류)이라 9장 급소 서술의 핵심 — 절대 축약·완화 금지.
3. **`axioms`(25부, 공리계)**는 기능 열 항목(틀 채택 평가) 다수 포함 — % 표기 대신 라벨 유지.
4. **worldview.json의 `registered_predictions`(예측 α–η, 7건)**는 index.html 어디에도 산문으로 없을 수 있음 — 9·10장에 별도로 완역 삽입 필요(원천: `data/worldview.json` 직접, 커버리지 표에 별항 등재).
