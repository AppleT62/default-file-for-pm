# 웹 보고서 — 「미래는 가중되어 있다」 쉬운말판

`easy-report/`의 13개 장을 하나의 읽기용 웹 페이지로 묶은 산출물.

- `index.html` — 완성본(단일 파일·외부 의존 없음). 브라우저로 바로 열면 된다.
- `build.py` — 생성기. `easy-report/*.md`를 읽어 `index.html`을 다시 만든다.

## 다시 만들기

완역본 원고를 고친 뒤:

```
python3 easy-report/web/build.py
```

원고가 유일한 진실 원천이고 `index.html`은 파생물이다 — HTML을 직접 고치지 말 것(다음 빌드에 덮어써진다).

## 설계 메모

- **색**: 차가운 슬레이트 지면 + 황동 액센트(계측 장비 위의 인간 판단). 판정 칩만 의미색으로 분리.
- **타입**: 명조(장 제목·인용) / 고딕(본문) / 모노(신념도·회차 숫자, tabular-nums).
- **레이아웃**: 좌측 고정 목차 레일 + 66자 본문 단, 상단 읽기 진행바. 900px 이하에서 장 선택 드롭다운으로 전환.
- 히어로의 곡선은 표제 명제("미래는 기울어져 있다")를 그대로 그린 기울어진 분포. 라이트/다크 테마와 `prefers-reduced-motion`을 따른다.
